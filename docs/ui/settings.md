# Настройки UI и звука — «ГТА 6»

Единственный источник настроек интерфейса и громкости —
`scripts/ui/ui_settings.gd`. Это статический класс без автолоада: сцены
подключают его через `const UiSettings = preload("res://scripts/ui/ui_settings.gd")`.
Читают его HUD, DialogueUI и PauseMenu, поэтому изменение в паузе сразу видно всем.

Файл: `user://settings.cfg` (в Windows — `%APPDATA%\Godot\app_userdata\ГТА 6\settings.cfg`).

## Секции

| Секция | Ключ | Смысл |
|---|---|---|
| `[audio]` | `master`, `music`, `sfx`, `voice` | линейная громкость шин 0…1 |
| `[input]` | `mouse_sensitivity` | сырая чувствительность мыши (`Player.mouse_sensitivity`) |
| `[video]` | `fullscreen` | полный экран |
| `[ui]` | `dialogue_font_step` | 0/1/2 — мелкий/обычный/крупный шрифт диалога |
| `[ui]` | `hints_visible` | подсказки «E — …» на HUD (переключаются клавишей M) |
| `[ui]` | `high_contrast` | высокий контраст подсказок |
| `[meta]` | `version` | версия формата (`CONFIG_VERSION`) |

Громкость дополнительно применяется через `AudioManager.set_bus_volume()`
и дублируется в его `user://audio.cfg`.

## Громкость по умолчанию

| Шина | дБ | Линейно |
|---|---|---|
| Master | 0 | 1.0 |
| Music | −12 | 0.2512 |
| SFX | −8 | 0.3981 |
| Voice | −4 | 0.6310 |

## Защита от «мёртвого нуля» (t47)

Раньше на свежем профиле (`settings.cfg` ещё нет) значения подхватывались из
`AudioManager`, и если он отдавал `0.0`, этот ноль при первом закрытии паузы
уезжал в `settings.cfg`/`audio.cfg` — игра замолкала навсегда. Теперь:

- громкость из `AudioManager` читается только когда `is_ready()` (сигнал
  `audio_ready`); до готовности/при ошибке — из `user://audio.cfg`, затем
  `DEFAULT_VOLUME`;
- значение `≤ 0.001` от `AudioManager`/`audio.cfg` считается отсутствием
  значения и заменяется заводским (ноль лечится автоматически);
- `save_settings()` не пишет ноль, если он не пришёл из `settings.cfg` и не
  выставлен ползунком в паузе; при лечении в лог уходит
  `[ui_settings] <шина>=0 без выбора пользователя — беру <значение>`;
- «сиротский» ноль в `settings.cfg` (записан старым багом) лечится заводским
  значением: осознанный мьют помечается ключом `[audio] muted_<шина>=true`,
  без этой отметки ноль считается испорченным;
- осознанный мьют (ползунок Master в 0) сохраняется как 0 вместе с отметкой и
  переживает перезапуск.

Проверка: `tests/settings_smoke.tscn` (чистый профиль → 1.0; пользовательские
0.35 → остаются; битый `audio.cfg` с нулями → лечится; мьют ползунком → 0.0).
