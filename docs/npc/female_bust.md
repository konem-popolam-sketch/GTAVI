# Женский силуэт humanoid (body_shape)

Задача: «моделькам женщин добавь грудь» — то есть **силуэт**, а не отдельные шары
поверх торса. Модель процедурная (`scripts/npc/humanoid.gd`), пол задаётся не
отдельной моделью, а параметром силуэта.

## Что сделано

В `scripts/npc/humanoid.gd` добавлен параметр `body_shape` и для значения
`female` при сборке к узлу **`Chest`** добавляются два сегмента — `BustL` и `BustR`
(`SphereMesh` с неравномерным масштабом, материал — тот же `jacket`, что у торса).

- никакой отдельной геометрии сосков, никакой анатомии ниже груди;
- новых сцен и новых узлов в `scenes/actors/humanoid.tscn` нет — всё строится кодом.

## Числа

| Параметр | Значение | Комментарий |
|---|---|---|
| `BUST_RADIUS` | 0.062 м | радиус сферы до масштабирования |
| `BUST_SCALE` | (1.42, 0.76, 0.66) | шире, чем выше, и уплощена по глубине |
| Итоговый эллипсоид | ≈0.176 × 0.094 × 0.082 м | «полка» по груди |
| `BUST_OFFSET` | (±0.062, 0.088, −0.096) в системе `Chest` | x — полрасстояния между центрами, y — высота от низа торса, z — вперёд |
| Выступ от торса | ≈32 мм | передняя грань торса на z = −0.105 |
| Перекрытие сегментов | 52 мм по центру | поэтому форма сливается в один объём, а не в две накладки |
| Внешний край | x = 0.150 | внутри ширины торса (0.175) — габарит фигуры не меняется |
| Объём двух сегментов | ≈5.7 % от объёма торса | лимит задачи — ±6 % |

При смене `height_scale`/палитры грудь масштабируется вместе с корнем (она —
дочерний узел `Chest`), отдельного пересчёта не требуется.

## Как включается

```gdscript
# авто (по умолчанию): определить по npc_id родителя, иначе по палитре
humanoid.body_shape = "auto"
humanoid.set_body_shape("female")   # публичный метод, работает и в рантайме
humanoid.get_body_shape()           # -> "neutral" | "female" | "male"
humanoid.has_bust()                 # -> bool
```

Автоопределение (`_resolve_body_shape`, `NPC_BODY_SHAPES`):

| npc_id | силуэт |
|---|---|
| `mila`, `galya` | female |
| `kostya`, `foreman`, `timur` | male |
| `player` | male (выбран, чтобы протагонист читался как Нил) |
| нет npc_id | по палитре: `mila` → female, `player`/`kostya`/`foreman` → male, прочее → neutral |

`npc_id` читается у ближайшего родителя, у которого объявлено это свойство
(`NPC`), поэтому `scenes/actors/npc.tscn` и `scenes/main.tscn` править не нужно.
Метод `set_body_shape()` можно вызвать в любой момент — геометрия пересобирается
(старые сегменты удаляются, новые добавляются к `Chest`).

## Анимации

`BustL`/`BustR` — дети `Chest`, у них нет собственных треков в `idle`/`walk`/`run`,
поэтому они жёстко следуют за корпусом и не деформируются.

Замер в живом инстансе (порт моста 9091, экземпляр `humanoid.tscn` с
`set_body_shape("female")`):

```
idle:  chestRot=(0, 0, 0)               bustLocal=(-0.062, 0.088, -0.096)
walk1: chestRot=(-0.242, 0, 0.117)      bustLocal=(-0.062, 0.088, -0.096)  bustGlobal=(-0.0622, 1.4088, -0.0923)
walk2: chestRot=(-0.486, 0, -0.373)     bustLocal=(-0.062, 0.088, -0.096)  bustGlobal=(-0.0614, 1.4096, -0.0907)
```

Локальная позиция сегментов при ходьбе не меняется, а мировая едет вместе с
`Chest` — то есть анимация их не деформирует, а переносит. `get_part_count()` =
29 для `female` (27 для `neutral`/`male`).

## Как выглядит

- **Мила** (`npc_id=mila`, палитра `mila`) — `body_shape=female`, 29 сегментов:
  `docs/shots_t34/01_mila_bust.png` (три четверти) и `02_mila_front.png` (фас):
  видна широкая мягкая линия груди в нижней половине торса, габарит плеч не меняется.
- **Галя** (`npc_id=galya`, палитра `npc` — серый китель) — `docs/shots_t34/03_galya_bust.png`:
  те же два сегмента читаются на сером торсе.
- **Игрок, Костя, Прораб, Тимур** — `body_shape=male`, груди нет, силуэт прежний.

## Публичный API

Существующий API не изменён: `apply_skin()`, `get_skin_names()`, `set_height_scale()`,
`get_hip_height()`, `set_locomotion_enabled()`, `play_idle/walk/run()`,
`get_current_animation()`, `get_part_count()`, `get_animation_player()`.

Добавлено: `set_body_shape()`, `get_body_shape()`, `has_bust()`, экспорт `body_shape`.
