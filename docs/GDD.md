# НОЧНАЯ СМЕНА — дизайн-бриф

**Жанр:** короткая сюжетная 3D-прогулка (narrative walking sim) с одной сюжетной развилкой.
**Движок:** Godot 4.7.2 (Forward+, GDScript).
**Объём:** одна локация, 10–15 минут прохождения, 4 сюжетных узла, одна концовка из двух.
**Ассеты:** только процедурные примитивы движка (CSG/BoxMesh/CylinderMesh) + встроенные шрифты. Внешних ассетов нет.

## Завязка

Город на побережье, 22:40. Курьер по имени Нил должен передать посылку в переулке у ночного магазина
«Луна». Посылка тяжёлая, коробка перевязана. Прораб ждёт у пирса и говорит мало.

Локация — один квартал: площадка с асфальтом, два здания, магазин с неоновой вывеской, парковка
с ограждением, закуток между домами, спуск к воде (пирс) и фонари вместо солнца.

## Персонажи (неигровые, простые капсулы с подсветкой)

| Кто | Где | Роль |
|---|---|---|
| Мила, продавщица | у входа в «Луну» | говорит о том, что за ней второй день кто-то ходит |
| Прораб | у пирса | забирает посылку, платит, просит не задавать вопросов |
| Бомж Костя | под фонарём у ограждения | знает, что в коробке, торгуется за сигареты |
| Голос в трубке | автоответчик у входа | вскрывает контекст на финале |

## Игровой цикл

- WASD — ходьба, Shift — бег, Space — прыжок, E — взаимодействие, Esc — пауза.
- Камера от третьего лица, вращение мышью, приближение колесом.
- Подходишь к объекту с маркером — появляется подсказка «E — поговорить».
- Диалог — панель снизу: имя, реплика, варианты ответа (1–3), выход по E.
- Цель показывается в HUD сверху: «Отнеси посылку к пирсу».
- Одна развилка влияет на финальную реплику: отдать посылку / открыть коробку.
- Позиция игрока сохраняется в `user://save.json` (пишет `scripts/game/save_system.gd`) и восстанавливается при запуске.
- Победа = доиграл финальный диалог; появляется титр «КОНЕЦ» и номер концовки.

## Структура файлов (контракт между задачами)

```
project.godot                  # уже есть, автолоад McpInteractionServer
scenes/main.tscn               # корневая сцена мира: World + Player + UI  (владелец: T1)
scenes/world/block.tscn        # геометрия квартала + свет              (T1)
scenes/player/player.tscn      # игрок + камера                         (T2)
scenes/actors/npc.tscn         # капсула NPC + маркер + зона диалога    (T2)
ui/hud.tscn                    # цель, подсказка взаимодействия, титр   (T3)
ui/dialogue.tscn               # панель диалога                         (T3)
scripts/world/world.gd         # сборка мира, свет, окружение           (T1)
scripts/player/player.gd       # движение, камера                       (T2)
scripts/player/interactor.gd   # raycast, поиск интерактивных объектов  (T2)
scripts/npc/npc.gd             # данные NPC, маркер, старт диалога      (T2)
scripts/dialogue/dialogue_data.gd + data/*.json  # контент диалогов     (T3)
scripts/dialogue/dialogue_manager.gd             # автолоад логики      (T3)
scripts/quest/quest_state.gd                     # автолоад состояния   (T3)
scripts/ui/hud.gd, dialogue_ui.gd                # связка UI              (T3)
scripts/game/save_system.gd                      # user://save.cfg        (T3)
```

Владелец файла один. Чужие файлы не правим — только через сообщение капитану.

## Палитра и настроение

Ночь, влажный асфальт, тёплый натриевый свет фонарей, неон магазина (маджента/циан), туман 0.02,
лёгкий bloom. Никакого яркого дневного света. Силуэты — читаемые, геометрия крупная.

## Критерий готовности (definition of done)

1. `godot --headless --path . --quit-after 300` не печатает ошибок скриптов и сцен.
2. Игра запускается, видна локация, игрок ходит, камера вращается.
3. Все 4 диалога открываются и закрываются, выбор в финале работает.
4. Сохранение позиции переживает перезапуск.
5. Скриншот из `python tools/bridge.py shot` показывает ночной квартал, а не серую пустоту.
