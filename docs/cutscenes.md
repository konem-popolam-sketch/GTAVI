# Катсцены «Ночной смены» — ТЗ для постановщика (фаза 2.1)

Версия 1.0. Автор: Тору (narrative-director). Для: Ичиго (логика `CutsceneDirector`), Тандзиро (камера игрока), Рэм (врезка в `scenes/main.tscn`), Кэйко (титр, затемнение, субтитры), Харуки (звук), Эрен (маркеры/реквизит), Эми (реплики).

Три катсцены. Ничего, кроме этого файла и `docs/story_branch_weapon.md`, задача не меняет: библия, JSON-диалоги, сцены и скрипты — чужие.

Общие числа: 3 сцены (4 версии), 14 узлов реплик, 43 новых голосовых файла вместе с веткой «Ствол» (см. §5).

---

## 0. Что считается катсценой

Катсцена — это отрезок, где **управление игроком выключено**, камера принадлежит `CutsceneCamera`, а реплики идут по таймлайну, а не по нажатию E. Всё остальное (диалоги, квест-цели, сохранение) продолжает работать как раньше.

Три правила, которые нельзя нарушать:

1. Катсцена никогда не «запирает» игрока навсегда: авто-выход по таймеру, скип по Space/Esc, всегда возврат к обычной камере и управлению.
2. Катсцена не ломает квест: её сюжетные эффекты (флаги, цель) применяются и при скипе, и при просмотре. Скип пропускает картинку, но не состояние.
3. Катсцена проигрывается один раз за прохождение: флаг в `QuestState`, сохраняется в `user://save.json` вместе с остальными.

## 3. Катсцена 3 — финал ветки «Ствол»

Две версии одной сцены. Выбор версии — в `CutsceneDirector`:

```
версия A (cut_weapon):     сразу после диалога guard_confront, если weapon_discharged
версия B (cut_weapon_alt): после финального выбора, если ending_id == 2 и weapon_discharged
иначе:                     катсцены нет, обычный титр
```

Версия A — это и есть финал ветки: выстрел, уход Проверяющего и передача ствола Косте показаны катсценой, а не текстом, поэтому в диалоге `guard_confront` выстрела нет — только выбор и флаг. После A сразу идёт короткий `guard_aftermath`. Версия B — альтернатива для второй концовки и играется после финального выбора; у неё отдельный флаг (`cut_weapon_alt_seen`), поэтому B не блокируется просмотренной A.

## 4. Технические требования к системе катсцен

### 4.1. Состав (владельцы)

| Файл (предлагаемый) | Что | Владелец |
|---|---|---|
| `scenes/cutscene/cutscene.tscn` | `Node` с `CutsceneDirector` + `CutsceneCamera` + `Fade` (ColorRect) | Ичиго / Рэм |
| `scripts/cutscene/cutscene_director.gd` | таймлайн, скип, флаги, выдача управления | Ичиго |
| `scripts/cutscene/cutscene_step.gd` | один шаг: `t`, действие (`line`, `camera`, `sfx`, `flag`, `title`) | Ичиго |
| `scenes/ui/cutscene_fade.tscn` | затемнение 0.4 с | Кэйко |
| `ui/dialogue.tscn` (доработка) | режим субтитров без выбора: `show_cutscene_line(speaker, text)` / `clear_cutscene_line()` | Кэйко |
| `scenes/main.tscn` | врезка узла `Cutscenes` (после `Npcs`) | Рэм (единственный владелец main.tscn) |
| `scenes/objects/weapon.tscn` | проп ствола (в катсцене 3) | Рэм/Сакура |

### 4.2. Камера

1. `CutsceneCamera` — **не** ребёнок `Player`: отдельный `Camera3D` в узле `Cutscenes`, `current = false` до старта, `near = 0.05`, `fov` из сцены.
2. Старт: `player.get_camera().current = false`, затем `cutscene_camera.current = true`. Конец — обратно. Камера игрока (`Player/SpringArm3D/Camera3D`) продолжает считать spring arm в `_process`, но кадр не выводит; это безопасно и переделки `player.gd` не требует.
3. `CutsceneCamera` не должна получать ввод и не должна иметь `SpringArm3D`: движение — только по таймлайну или фиксированной позицией.
4. Клиренс: все позиции из §1–§3 проверены на ≥0.6 м до стен; если сцена меняется, позиции перепроверяет Эрен (не «на глаз»).

### 4.3. Ввод и блокировки

| Что | Как |
|---|---|
| Игрок не двигается | `player.set_controls_enabled(false)`; `player.set_mouse_captured(false)`; `Input.mouse_mode = MOUSE_MODE_VISIBLE` |
| Взаимодействие молчит | `player.get_interactor().set_active(false)` (метод добавить; иначе — `require_proximity=false` на время) |
| Диалоги молчат | в `DialogueManager.start_dialogue()` ранний выход: `if CutsceneDirector.is_playing(): return false` |
| Пауза не открывается | `PauseMenu._pause_blocked()` дополняется `or CutsceneDirector.is_playing()` |
| HUD скрыт | `HUD.set_cutscene(true)` → `_update_visibility()` учитывает флаг (цель, счётчик, подсказки, имена NPC — скрыть) |
| Субтитры | `DialogueUI.show_cutscene_line(speaker, text)` без вариантов, без «E»; озвучка — `AudioManager.play_voice(dialogue_id, node_id)` |
| Скип | `_input` (не `_unhandled_input`): Space или Esc; `get_viewport().set_input_as_handled()`; скип необратим, возврата нет |
| Автовыход | по таймеру длительности, ±0.1 с |

### 4.4. Флаги, сейв, повтор

1. На старте катсцены: `QuestState.set_flag("<id>_seen", true)`; `QuestState.auto_save_enabled = false`.
2. На конце (в том числе после скипа): применяются все шаги `flag`/`objective` из таймлайна, `auto_save_enabled = true`, `QuestState.set_flag` последнего шага триггерит автосейв.
3. Загрузка: `CutsceneDirector._ready()` проверяет флаг и не запускает сцену повторно.
4. Если игрок сохранился и вышел посреди катсцены (например, аварийно) — при загрузке сцена не проигрывается, состояние берётся из флагов, игрок появляется на позиции конца сцены (позиции в §1–§3).
5. Титр концовки (`HUD.show_ending`) показывается после катсцены, а не во время; при скипе — сразу.

### 4.5. Звук

- Реплики — только через `AudioManager.play_voice` (как в диалогах), чтобы работали шины и громкость.
- `gunshot`, `tape_stop`, `door_creak`, `tape_hiss` — новые SFX, просить у Харуки (или сгенерировать из существующих: `assets/audio/sfx/`).
- На время катсцены музыка не меняется; амбиент приглушается на −6 dB (если `AudioManager` умеет `set_bus_volume("Ambience", ...)` — вернуть после).

### 4.6. Ограничения по производительности

- Не более 1 активной кат-камеры; камера игрока не удаляется и не пересоздаётся.
- Таймлайн — массив словарей `{t: float, type: String, ...}`; никаких `await` внутри `_process`.
- `CutsceneDirector` не должен аллоцировать каждый кадр (кэш позиций/целей).

## 6. Приёмка (чек-лист)

1. Новая игра → `cut_prologue` играется один раз, 8 с, скипается Space и Esc, после скипа управление сразу работает.
2. Загрузка сохранения → пролог не играется, камера и управление в норме.
3. `twin_box_found` → `cut_box` играется один раз; после скипа витрина «Луны» всё равно гаснет, цель меняется.
4. `weapon_discharged` → сразу после `guard_confront` играется `cut_weapon` (12 с), затем `guard_aftermath`; ствол переходит Косте, в инвентаре пусто.
5. `weapon_discharged` + вторая концовка → после финального выбора играется `cut_weapon_alt` (10 с), титр «Голос»; версия B не блокируется просмотренной A.
6. Без ствола ни одна катсцена, кроме пролога и `cut_box`, не играется.
7. Во время любой катсцены: нет подсказки «E — поговорить», нет паузы по Esc (Esc = скип), нет движения игрока мышью/WASD, HUD скрыт.
8. В логе headless: нет `SCRIPT ERROR`, `Camera3D` не «прыгает» после возврата (тест: снять два скриншота до/после).
9. Повторный запуск сцены в той же сессии не проигрывает катсцену (флаг).
10. Все 43 новых реплики находятся в манифесте (`[audio] ... 43 файла`), субтитры совпадают с текстом.
