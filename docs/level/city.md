# Город «Ночной смены» (T32)

Статус: город вокруг исторического центра реализован в
`scenes/world/block.tscn` (+ процедурная сборка в `scripts/world/world.gd`).
Исторический квартал («Луна», пирс, переулки, двор, крыша) сохранён: все старые
POI, NPC-слоты, спавн и координаты не менялись. Точечные правки для связи с городом:
северная стена `Perimeter/WallNorth` разделена проёмом ворот (x −3…3, z −26.4),
а контейнер из заднего прохода перенесён в Alley2 — иначе он перекрывал выход к
воротам (проход был 1.0 м вместо 1.2 м).

| Проезжая часть | 4 вертикальные + 5 горизонтальных улиц | ширина 10 м (две полосы), асфальт `asphalt_pbr` |

## 2. Координатная сетка

Улицы (центры, ширина 10 м):

- вертикальные: x = −120, −40, 40, 120 (от z = −390 до z = −35);
- горизонтальные: z = −40, −110, −180, −250, −320 (от x = −180 до x = 180);
- южная площадь соединяет улицу z = −40 с воротами центра: z −35…−32 по всей ширине;
- кольцо для машины: прямоугольник x = ±120, z = −40…−250, длина ≈ 900 м.

Кварталы (между улицами): x-диапазоны
`[−180,−125] [−115,−45] [−35,35] [45,115] [125,180]`;
z-диапазоны `[−105,−45] [−175,−115] [−245,−185] [−315,−255] [−390,−325]`.
В каждом квартале 3 дома (кроме спецкварталов), случайные высоты 4–12 этажей,
детерминированный seed — расстановка не «прыгает» между запусками.

Спецкварталы:
- `колонка 2, ряд 0` — клуб: корпус 12×12 м, h = 12 м, неоновая вывеска «КЛУБ»;
- `колонка 3, ряд 0` — автосервис: 16×9×10 м, ворота, вывеска «СЕРВИС»;
- `колонка 1, ряд 1` — заправка: навес 18×12 м на 4 опорах, 2 колонки, стела.

### 2.1. Клуб: фасад разобран, не собирать обратно в цельный бокс (T50)

Это важно при следующих правках города — иначе витрина снова станет «светящейся
заливкой», как уже было до T50.

- Запись клуба в `_city_houses` имеет `manual_facade = true`, поэтому
  `_build_city_facades()` **пропускает** её; цельного 12×12×12 бокса в батче
  фасадов больше нет.
- Вместо него `_build_city_club()` собирает: верхние этажи 12×8.8×12
  (низ на y≈3.5) и ground-floor стены по бокам/сзади — всё батчем `facade_club`
  (commercial-материал). Передняя часть первого этажа открыта под витрины.
- За стеклом — тёмная ниша `interior_wall_dark` глубиной ~1.35 м: задняя стена
  на z = −67.45, пол, потолок; внутри:
  - барная стойка `bar_counter_wood` 4.2×1.1×0.55 (z = −66.85),
  - две полки `metal_pbr` (z = −67.05),
  - 4 «бутылки» `CSGCylinder3D` r=0.04 h=0.3 без коллайдеров,
  - два стула-силуэта и полоса `neon_strip_magenta` на задней стене,
  - полосовой тёплый glow-квад у пола (emission 1.1).
- Свет: два витринных Omni из T48 перевешены внутрь ниши (x=2.2/3.4, z=−67):
  1.2/3.5 (≈2700 K) и 0.9/4, без теней. Бюджет города остаётся 58/60.
- Витринные секции клуба: 2 модуля по 3.2 м, по 3 секции 0.95×2.4, импост 0.08,
  дверь 1.0×2.4; один сегмент — `storefront_shutter` (без glow за ним).
- Не добавлять коллайдеры в нишу и не заменять разобранный фасад одним
  `_batch_box("facade_club", ...)` размером 12×12×12: вернётся стена за стеклом.

## 4. API (scripts/world/world.gd)

```gdscript
$World.get_spawn_transform()   # как раньше (центр, 0, 0.1, 10)
$World.get_poi(&"POI_Club")    # как раньше, новые имена работают
$World.get_npc_slot(&"NPC_Mila")
$World.get_poi_names()         # 16 имён, сортировано
$World.get_city_bounds()       # AABB: pos (−180, −2, −390), size (360, 40, 358)
$World.get_road_path()         # PackedVector3Array: замкнутое кольцо, 47 точек
$World.get_city_node_count()   # число узлов процедурного города (для QA перфа)
$World.dump_world_summary()    # POI, слоты, свет, границы, длина кольца
```

`get_city_bounds()` покрывает городскую сетку (360×358 м), исторический центр
примыкает с юга; вода — южнее z = 22.

## 5. Маршрут для машины

`get_road_path()` — кольцо по осям улиц x = ±120 и z = −40…−250:
юг → запад → север → восток → юг, последняя точка совпадает с первой.
47 точек, шаг 20 м, длина ≈ 900 м. На 25–30 м/с полный круг ≈ 30–36 с,
прямая по любой улице 240–350 м ≈ 8–14 с. Дорога свободна: дома стоят внутри
кварталов с отступом ≥ 6 м от бордюра, фонари — без коллизий.

Для интеграции с машиной: спавн машины удобно у гаража — `POI_Garage`
(84, 0.15, −58), выезд на улицу z = −40; либо на кольце в точке (−120, 0, −40).

## 6. Свет и производительность

- Всего OmniLight3D: 51 (13 исторических + 38 городских); бюджет ~60 соблюдён.
- Городские фонари: energy 2.8, indirect 0.6, range 12 — как у исторических
  (2.2–3.8 / 10–18). Тени включены только у 8 фонарей ближней части кольца,
  у остальных выключены.
- Геометрия города — `StaticBody3D` + `BoxShape3D`; визуал — `MultiMeshInstance3D`
  (дороги/кварталы/дома/окна/разметка/столбы), поэтому узлов ~400, а не тысячи.
- `--headless --quit-after 600` проверяется капитаном; число узлов печатает
  `dump_world_summary()` и проверяет `tests/city_smoke.tscn`.

## 7. Проверка

```powershell
# импорт ресурсов
& .\tools\Godot_v4.7.2-stable_win64_console.exe --headless --path . --import

# главная сцена, 600 кадров
& .\tools\Godot_v4.7.2-stable_win64_console.exe --headless --path . `
    --quit-after 600 --log-file tools\t32_hl.log

# смоук города
& .\tools\Godot_v4.7.2-stable_win64_console.exe --headless --path . `
    res://tests/city_smoke.tscn --log-file tools\city_smoke.log
```

Ожидаемо: exit 0, нет `SCRIPT ERROR`; в смоуке — `CITY SMOKE OK`.
Смоук проверяет: bounds ≥ 350×350, ≥ 8 POI (включая клуб/гараж/заправку/мостик),
спавн на полу, кольцо замкнуто и ≥ 20 точек, все сегменты кольца без препятствий,
324 пробы на дыры в геометрии, отсутствие пустых коллизий и CSG-коллизий в городе,
бюджет OmniLight ≤ 60, число узлов < 5000.
