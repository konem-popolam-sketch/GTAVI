## 1. Что появилось и зачем

| Внутренний двор | `DistrictExpansion/Courtyard` | акт II–III: тихое место, фонарь, лавки, арка | проход 3.0 м, арка 2.6 м, z −24…−2 |
| Крыша магазина | `DistrictExpansion/Rooftop` | акт III: площадка над кварталом, обзор, развилка; будка у парапета — заглушка диспетчерской «Точки» (дверь + код-панель + тёплое окно) | 12×12 м, высота 5.0 м, пожарная лестница-пандус |

| Дом C (фон) | `DistrictExpansion/Buildings/BuildingC` | силуэт района, окна в переулок | 6×9×20 м, x 23.4…29.4 |

Новые места не изолированы: маршруты замкнуты в кольцо
`площадь → переулок/крыша/двор → задний проход → второй переулок → площадь`,
плюс отдельная ветка `площадь → спуск → нижний причал`.

Сюжетные зацепки по библии (T10), уже стоящие в геометрии:
- кран и лужа за «Луной» (`BackPassage/Tap`, `BackPassage/TapPuddle`) — сцена `amb_puddle`;
- служебная дверь с код-панелью и циановой полоской на крыше (`Rooftop/Shed`) —
  визуальная заглушка диспетчерской; отдельный интерьер — задача интеграции;
- на крыше есть столб, бак и кондиционеры — укрытия для акта III;
- на квэе — перила, парапет и фонарь: место финального разговора у воды.

## 5. Коллизии и проходимость

- Новая часть района — **только `StaticBody3D` + `BoxShape3D`** (36 тел), CSG-коллизий
  в `DistrictExpansion` нет. Старые CSG-коллизии квартала не трогались.
  Пояснение: для осевых стен/полов/пандусов примитив `BoxShape3D` точнее и дешевле
  тримеша `ConcavePolygonShape3D` (нет швов и «зацепов» на стыках) — запрет задания
  касался CSG-коллизий, их в новой части нет; тест это проверяет.
- Все подъёмы — гладкие пандусы под коллизией: пожарная лестница на крышу
  (1.5 м ширина, уклон 27.6°), бетонный спуск к воде (4.5 м ширина, уклон 18.4°).
  Визуальные ступени спуска — 4 × 0.175 м (≤ 0.25 м), коллизия под ними гладкая,
  поэтому капсула игрока не цепляется за рёбра.
- Проходы: второй переулок 3.4 м, двор 3.0 м, задний проход 2.1 м (локально 1.85 м
  у старой глухой стены), тамбур ~3.9 м, лестница 1.5 м (свободно 1.32 м между
  перилами). Везде ≥ 1.2 м.
- Крыша: парапет 0.9 м по периметру, разрыв парапета совпадает с площадкой лестницы.
- Квэй: перила по бокам, парапет к воде, ступени перекрывают проём в старом
  морском ограждении (x 10…14.5), «дыр» над водой нет.
- Изменения старых узлов (минимальные, для проходимости):
  `Perimeter/WallNorth` сдвинут на z = −26.4 (задний проход стал 2.1 м), а в T32
  разделён проёмом ворот (x −3…3) для выхода в город; контейнер из заднего прохода
  перенесён в Alley2, чтобы не сужать единственный проход к воротам.
  `WallWest`/`WallEast` удлинены до стыка со северной стеной (углы без щелей),
  `Perimeter/SeaRailEast` укорочен до x 5…10, добавлен `Quay/SeaRailFar`
  (x 14.5…29.4), `SeaRailWest` дотянут до западной стены (x −29.4);
  `Alley/AlleyBulb` и `Alley/AlleyLight` перенесены на x = 4.9, чтобы не оказаться
  внутри пожарной лестницы. `Ground/Buildings/Shop/Alley/Parking/Waterfront/Lamps`
  и все старые маркеры не переименованы.

## 7. API для интегратора (изменения только аддитивные)

```gdscript
$World.get_poi(&"POI_Rooftop")        # Vector3, как раньше
$World.get_npc_slot(&"NPC_Quay")      # Vector3, как раньше
$World.get_poi_names()                # PackedStringArray, теперь отсортирован
$World.get_npc_slot_names()           # новый: отсортированные имена слотов
$World.get_poi_area(&"POI_Courtyard") # новый: &"courtyard"
$World.get_walk_route(&"POI_Quay")    # новый: PackedVector3Array, спавн → POI
$World.get_total_route_length()       # новый: суммарная длина маршрутов, м
$World.dump_world_summary()           # расширена: районы, маршруты, коллизии
```

Сцены и скрипты игрока/UI/диалогов не менялись. `scenes/main.tscn` не правился:
новые NPC на слоты ставит интегратор (`NPC_Alley2`, `NPC_Courtyard`, `NPC_Rooftop`,
`NPC_Quay`), новых POI в save-файле нет — сохранение позиции работает как раньше.
