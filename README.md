# ГТА 6

Компактная сюжетная 3D-игра на **Godot 4.7.2** (Forward+): ночной город 360×358 м, три акта,
26 диалогов, три концовки, озвучка, оружие, машина, интерьеры и катсцены. Внутриигровое
название ночи — «Ночная смена». Полный проход — примерно 25–40 минут.

## Запуск

**Самый простой способ — ярлык «ГТА 6» на рабочем столе** (или файл `play.bat` в этой папке):
двойной клик, и игра стартует. `play.bat --fresh` начинает новую игру, без флага продолжается
сохранённая.

Из терминала:

```powershell
.\play.bat
```

Напрямую движком (так же, как делает `play.bat`):

```powershell
.\tools\Godot_v4.7.2-stable_win64.exe --path .
```

Открыть редактор:

```powershell
.\tools\Godot_v4.7.2-stable_win64.exe --editor --path .
```

### Если игра скачана с GitHub

Движок в репозитории лежит **архивом** `tools/Godot_v4.7.2-stable_win64.exe.zip` (82 МБ вместо
172 МБ в распакованном виде — так GitHub пропускает файл). Голосовых моделей Piper в архиве нет:
они нужны только для перегенерации озвучки (`tools/gen_voice.ps1`), а готовые реплики уже лежат
в `assets/audio/`.

Порядок действий — просто запустить `play.bat`. Он сам:

1. распакует движок из `tools/Godot_v4.7.2-stable_win64.exe.zip`, если exe ещё нет;
2. при самом первом запуске выполнит `--headless --import` — Godot построит кэш ресурсов
   (`.godot/`, 1–2 минуты, в консоли виден прогресс). **Без этого шага игра падает**:
   `Parse Error: Identifier "SaveSystem" not declared`, `Unable to open file: res://.godot/imported/....ctex`
   и в итоге не загружается `main.gd`, поэтому кнопка «НАЧАТЬ» не реагирует;
3. запустит игру.

Если импорт когда-нибудь понадобится повторить вручную:

```powershell
.\tools\Godot_v4.7.2-stable_win64_console.exe --headless --path . --import
```

Если `play.bat` при двойном клике выдаёт ошибки вида `'fresh' is not recognized` или
`'.7.2-stable_win64.exe" (' is not recognized` — значит файл распакован с LF-переводами строк
(старые архивы до коммита `dae4b0c`). Скачай архив заново — в актуальном `play.bat` лежат CRLF.

Сообщения вроде `Could not create directory: 'user://logs'` и `Failed to read the root
certificate store` в консоли — известный шум, на игру не влияют.

Сообщения вроде `Could not create directory: 'user://logs'` и `Failed to read the root
certificate store` в консоли — известный шум песочницы Windows, на игру не влияют.

## Что есть в игре

- **Сюжет:** три акта, 26 диалогов (207 узлов), развилки, три концовки; ветка «Ствол»
  открывается, если найти вторую коробку.
- **Озвучка:** 203 реплики, 10 персонажей на 4 голосовых моделях с разными питчем и эффектами.
- **Звук:** мягкий дождь (пик −6 dBFS), городские петли, шаги, музыка, SFX оружия и машины;
  пять шин, все регулируются в паузе.
- **Город:** 360×358 м, 16 точек интереса, кольцевая дорога ~900 м, 175 зданий с коллизиями.
- **Оружие:** пистолет с подбором, хитсканом, магазином 8/24, перезарядкой и сохранением патронов.
- **Машина:** полноценная езда до 108 км/ч, камера-погоня, звук двигателя от скорости.
- **Интерьеры:** клуб («Луна») и магазин со входом через дверь, а не «картинкой» на фасаде.
- **Катсцены:** пролог, сцена с коробкой и сцена с оружием — с пропуском и без повторов после загрузки.
- **Люди:** процедурные humanoid-модели двух силуэтов, анимации ходьбы; Костя и Тимур ходят
  по маршрутам, Мила и Галя стоят.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | ходьба / руль в машине |
| Shift | бег / полный газ в машине |
| Space | прыжок / ручник в машине |
| колесо мыши | зум камеры |
| E | взаимодействие, продолжить диалог, сесть в машину / выйти |
| F или ЛКМ | выстрел (при оружии в руках) |
| R | перезарядка |
| 1–3 | выбор реплики |
| Tab | журнал квеста |
| M | скрыть подсказки |
| Esc | пауза / выход (сохраняет позицию) |

При запуске показывается титульная плашка «ГТА 6» с этим списком — нажми любую клавишу
или кликни, чтобы начать.

## Сохранение

Прогресс лежит в `user://save.json` (в Windows — `%APPDATA%\Godot\app_userdata\ГТА 6\`):
позиция, стадия квеста, инвентарь, флаги, патроны и концовка. После переименования игры старый
сейв из папки прежнего названия (`...\GTAVI\save.json`) переносится автоматически при первом
запуске — прогресс не теряется. Настройки звука и управления — в `settings.cfg` там же.

## Инструменты разработки

- `autoload/mcp_interaction_server.gd` — внутриигровой TCP-сервер (`127.0.0.1:9090`), даёт
  агенту доступ к живой игре: eval, дерево сцены, скриншоты, свойства, вызовы методов.
- `tools/bridge.py` — CLI-клиент к этому серверу; `tools/shot_cam.py` — кадры свободной камерой.
- `tools/gen_audio.py`, `tools/gen_voice_piper.py`, `tools/gen_pbr_textures.py` — генерация
  звука, озвучки и PBR-текстур (внешние CDN в этой песочнице заблокированы, ассеты процедурные).
- `tests/sprint_smoke.tscn` — headless-проверка бега на Shift: скорость шага и бега, наклон
  корпуса, прирост FOV и возврат камеры после отпускания. Успех печатает `SPRINT SMOKE OK`:

      .\tools\Godot_v4.7.2-stable_win64_console.exe --headless --path . tests/sprint_smoke.tscn

- `tests/music_playlist_smoke.tscn` — headless-проверка саундтрека: оба трека плейлиста
  находятся и грузятся, `play_music(..., loop = false)` доводит трек до конца и шлёт
  `music_finished`, а `AmbienceController` после конца трека включает следующий. Успех печатает
  `MUSIC PLAYLIST SMOKE OK`:

      .\tools\Godot_v4.7.2-stable_win64_console.exe --headless --path . tests/music_playlist_smoke.tscn

## Музыка

Саундтрек лежит в `assets/audio/music` (сейчас `634.mp3` и `634 master.mp3`) и играется
плейлистом: `scripts/audio/ambience_controller.gd` на старте перемешивает `music_playlist`,
запускает первый трек, а по его концу (сигнал `music_finished` из AudioManager) включает
следующий — по кругу. Чтобы добавить трек, положите файл в `assets/audio/music` и допишите имя
(без расширения) в `music_playlist` узла `Audio` в `scenes/main.tscn` или в значение по умолчанию
скрипта.
